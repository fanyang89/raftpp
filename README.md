# raftpp

A modern C++ implementation of the RAFT consensus algorithm.

## Documentation

Full documentation, guides, and API references are available at:

**https://raftpp.cc**

## Build

```bash
task cmake
task build
task test
task fmt
```

## Examples

See `examples/` for runnable examples, including:

- `minimal_node`
- `kvstore`
